Overview

First responders in disaster environments face dangerous, unknown terrain. ResQ is a lightweight swarm platform designed to map and assess hazardous areas before humans enter.

Three ESP32-based robots, each with complementary sensor loadouts, communicate over Wi-Fi to a central coordination system. Together they cover more ground, detect more hazards, and provide richer situational awareness than any single robot could alone.

System Architecture

Robot Platform

Three lightweight ESP32-based robots, each with complementary sensor configurations for redundant and overlapping coverage.

Communication

Wi-Fi mesh network connects all robots to a central coordination system with low-latency sensor data sharing.

Sensor Fusion

Complementary sensors across robots — combined data provides richer environmental awareness than individual readings.

Coordination

Central system aggregates data from all robots, identifies hazard zones, and coordinates coverage patterns.

Hazard Detection

Obstacle and hazard classification from fused sensor data with real-time alerts to the coordination system.

Embedded Control

All robot logic runs in Embedded C on ESP32 — optimized for low power and real-time response.

What I Learned

  • Designing distributed embedded systems where each node has limited compute but the swarm has collective intelligence
  • Wi-Fi communication reliability on ESP32 — packet loss handling and reconnection logic are essential in real environments
  • The value of complementary sensor configurations over identical sensor arrays for swarm coverage
  • Embedded C optimization for real-time control loops on resource-constrained hardware
