Overview

Robot vacuums like Roomba dock using IR sensors — but IR has limited range and is susceptible to interference. This project explored ultrasonic sensing as an alternative: longer range, works in low light, less vulnerable to stray signals.

The system uses a 40kHz ultrasonic beacon on the base station for coarse homing, then transitions to IR line-following for precise docking over a Qi wireless charging pad. No physical connector alignment needed — the robot just needs to get close enough.

Three-Phase Operation

01

Station Search

User presses button to activate. Robot spins while scanning for the 40kHz ultrasonic beacon. A red LED provides real-time feedback when signal is detected. If no signal found within 60 seconds (counter = 60,000 iterations), robot returns to idle. Once signal is confirmed above ADC threshold (100/255), robot moves toward it continuously.

02

Line Following → Docking

Left IR sensor detects black tape perimeter → robot transitions from ultrasonic to IR line-follow mode. Advances slightly, turns left slightly (prevents right IR false positives from the guide line). Line follows until right IR sensor crosses the perpendicular finish line at the Qi pad. Docking confirmed.

03

Idle / Charging

Motors halt. LCD displays "Dock Found". Green LED blinks on top to indicate active Qi charging. Battery percentage calculated continuously via ADC using 100×((DO−153)/41) and displayed on LCD. Button press at any phase pauses the robot and resumes from where it left off.

Hardware Architecture

Robot

Ultrasonic Receiver + LM393 Amp

Raw ultrasonic receiver output too weak for BS2's 1.4V input threshold. LM393 op-amp amplifies signal, ADC0831 converts it. Signal flag set when reading exceeds 100/255.

IR Sensors (×2)

Left: detects black tape perimeter to trigger mode transition. Right: detects finish line at Qi pad to confirm docking. Robot biases slightly left to prevent right IR false positives.

Qi Charging Circuit

Receiver mounted on laser-cut wood block at bottom of robot to minimize height gap. BMS 2S board safely charges 7.4V LiPo with cell balancing. ADC monitors battery voltage via voltage divider.

Battery Monitoring

7.4V battery → voltage divider → 3.7V → ADC with 5V reference → ~194 count at full charge. Formula: 100×((DO−153)/41) = battery %. Displayed on LCD.

Chassis Modifications

Parallax Boe-Bot with 3D-printed angled ultrasonic receiver support (prevents signal overlap), laser-cut LCD platform, raised Qi receiver block, and custom wooden power switch.

Drive System

Two Parallax continuous rotation servos. PULSOUT values: Stop=765, LFwd=773/RFwd=756, LBack=756/RBack=773. Differential drive for all turning modes.

Base Station

555 Timer Ultrasonic Beacon

  • NE555P in astable mode drives ultrasonic transducer
  • R1 = R2 = 12kΩ, C = 1µF
  • t_low = 8.316ms · t_high = 16.632ms
  • f = 1/(8.316+16.632)ms = 40kHz
  • Duty cycle = 66%
  • 40kHz chosen for best receiver sensitivity in testing

Black Tape Guidance System

  • Tape forms perimeter around ultrasonic transducer
  • Qi pad always positioned left of robot's approach angle
  • Tape line extends from perimeter to Qi pad
  • Perpendicular finish line crosses at Qi pad location
  • Right IR sensor crosses finish line → dock confirmed
  • Eliminates ambiguity of barrier-wall approach

What Worked

  • Ultrasonic + IR two-stage sensing was reliable for the full docking sequence
  • Qi wireless charging completely eliminated connector alignment problems
  • Works in total darkness — ultrasonic is light-independent
  • Clear state machine made debugging straightforward during testing

Limitations & Future Work

  • Signal bounce beyond ~30cm caused inconsistent detection — monostable 555 debounce circuit would help
  • No obstacle avoidance — bumpers or additional scanning sensor needed
  • Poor terrain traversal — higher traction wheels or increased motor power recommended
  • Replacing BS2 with ESP32C6 drops total cost from $321 → $68 and adds Wi-Fi/BLE

What I Learned

  • Multi-stage sensing pipelines are more robust than relying on a single sensor for the full task
  • Op-amp signal conditioning is essential when sensor output voltage falls below microcontroller logic thresholds
  • Embedded state machines need explicit idle/pause states — real users will always find edge cases you didn't design for
  • Qi coil height tolerance is tighter than expected — the wood spacer block was a critical mechanical fix
  • Systematic hardware debugging (one subsystem at a time) saved significant time vs. debugging the full integrated system
  • Component selection has enormous cost impact: ESP32C6 instead of BS2 = 4.7× cheaper with better capability
